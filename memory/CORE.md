# Architect — Core

Stable principles of Architect live here.

This file should change rarely.

## Current Core Principles

- Information is not stored in objects. It emerges from distinctions, contrasts, and recurring relational patterns.
- Concepts are reusable compressed structures produced from patterns.
- Concepts may contain and overlap with other concepts.
- Structures produced by Architect may recursively participate in the same mechanism again.
- External reality is ephemeral. Architect retains only its internally derived representation, never raw past reality.
- The engineering surrounding Architect should be minimal. Intelligence should emerge from Architect itself rather than from managers, planners, schedulers, or other intelligent machinery around it.
- Architect should be developed slowly and understood completely before complexity is added.
